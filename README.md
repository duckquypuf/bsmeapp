# How to edit this repo

## Step 1
Download GitHub for Desktop at https://desktop.github.com/download/

## Step 2
Sign in to your GitHub account on GitHub for Desktop

## Step 3
Open this repository on GitHub for Desktop

## Step 4
Clone this repository to your local machine

## Step 5
If you wish to edit something bigger than a small bug, click 'branches' then 'create a new branch' and give it an appropriate title

- When you are done with your changes click commit changes with a description of the changes, then push to origin.
- When you have completed your entire task with your branch, click merge with main or something and yeah ask someone pls.

However, if you only wish to edit a small bug, you may do so on your local machine on the main branch then commit and push to origin.
